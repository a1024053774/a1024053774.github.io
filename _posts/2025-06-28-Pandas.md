## Pandas 进阶操作、原笔记勘误与 SQL 对照

下方 2025-06-28 的初学笔记是跟着 Google ML 速成课和《动手学深度学习》走的：从 NumPy 数组建 DataFrame、加列、`head` / `iloc` / 切片取行、读 CSV、分离输入输出、填缺失值、转张量。这里先修掉原笔记里的两处错误，再补上数据分析常用的写法与 SQL 对照：

<div class="nb-note nb-note--warn"><b class="nb-tag">笔记里的错 1</b><code>inputs.fillna(inputs.mean())</code> 在新版 pandas 会报错：<code>Alley</code> 是字符串列，算不了均值（pandas 3.1 实测：<code>TypeError: Cannot perform reduction 'mean' with string dtype</code>）。d2l 原书接下来还有一步 <code>get_dummies</code>，原笔记里漏了。正确写法：</div>

```python
inputs = inputs.fillna(inputs.mean(numeric_only=True))
inputs = pd.get_dummies(inputs, dummy_na=True, dtype=float)
```

### loc 和 iloc

- `loc` 按**标签**，切片包含右端：`df.loc[0:2]` 是 3 行。
- `iloc` 按**位置**，切片不含右端：`df.iloc[0:2]` 是 2 行。
- 筛选 + 选列 + 赋值一步写完：`df.loc[df["amount"] > 200, "tag"] = "大单"`。pandas 3 默认 Copy-on-Write，`df["a"][0] = x` 这种链式赋值不再改到原表。

### 用一份电商订单练一遍

下面用一份示例电商订单数据串联常见的分析操作：

```python
orders = pd.DataFrame({
    "order_id": [1, 2, 3, 4, 5, 6],
    "user_id":  [10, 10, 11, 12, 12, 12],
    "category": ["服饰", "数码", "服饰", "美妆", "数码", "服饰"],
    "amount":   [199, 2999, 89, 259, 1599, None],
    "paid_at":  pd.to_datetime(["2026-09-01", "2026-09-03", "2026-09-03",
                                "2026-09-10", "2026-09-12", "2026-09-20"]),
})
users = pd.DataFrame({"user_id": [10, 11, 12], "city": ["上海", "北京", "上海"]})
o = orders.dropna(subset=["amount"])     # 第 6 单金额缺失，先去掉
```

**分组聚合**：每个品类几单、总额、均价，按总额排序。

```python
o.groupby("category")["amount"].agg(["count", "sum", "mean"]).sort_values("sum", ascending=False)
```

```python
m = o.merge(users, on="user_id", how="left")
m.pivot_table(index="city", columns="category", values="amount", aggfunc="sum", fill_value=0)
```

**transform 和 rank**：每单占该用户总消费的比例、在该用户内的金额排名。`transform` 返回和原表一样长，这是它和 `agg` 的区别，相当于 SQL 的窗口函数。

```python
o["rank_in_user"] = o.groupby("user_id")["amount"].rank(ascending=False)
o["user_share"]   = o["amount"] / o.groupby("user_id")["amount"].transform("sum")
```

### 其他高频小点

- `df.info()`、`df.describe()`、`df.isna().sum()`：拿到数据先看这三个。
- `value_counts()` 看类别分布；`nunique()` 看去重个数。
- `apply` 是逐行 Python 循环，慢；能用向量化运算或 `np.where` 就别用 `apply`。
- 重复值：`duplicated()` / `drop_duplicates(subset=[...])`。
- 大文件：`read_csv(..., usecols=[...], dtype={...}, chunksize=...)`；低基数字符串列转 `category` 省内存。

## Pandas 和 SQL 对照

同一套数据查询逻辑在 SQL 与 Pandas 里的对应写法：

<table>
  <thead>
    <tr><th>要做的事</th><th>SQL</th><th>Pandas</th></tr>
  </thead>
  <tbody>
    <tr><td>筛选</td><td><code>WHERE amount &gt; 200</code></td><td><code>df[df.amount &gt; 200]</code> 或 <code>df.query("amount &gt; 200")</code></td></tr>
    <tr><td>分组聚合</td><td><code>GROUP BY category</code></td><td><code>groupby("category").agg(...)</code></td></tr>
    <tr><td>分组后筛选</td><td><code>HAVING SUM(amount) &gt; 1000</code></td><td><code>g = ...sum(); g[g &gt; 1000]</code></td></tr>
    <tr><td>关联</td><td><code>LEFT JOIN users USING (user_id)</code></td><td><code>merge(users, on="user_id", how="left")</code></td></tr>
    <tr><td>窗口函数</td><td><code>RANK() OVER (PARTITION BY user_id ORDER BY amount DESC)</code></td><td><code>groupby("user_id")["amount"].rank(ascending=False)</code></td></tr>
    <tr><td>组内占比</td><td><code>amount / SUM(amount) OVER (PARTITION BY user_id)</code></td><td><code>amount / groupby(...).transform("sum")</code></td></tr>
    <tr><td>排序取前 N</td><td><code>ORDER BY sum DESC LIMIT 3</code></td><td><code>nlargest(3, "sum")</code></td></tr>
    <tr><td>空值</td><td><code>COALESCE(amount, 0)</code></td><td><code>fillna(0)</code></td></tr>
    <tr><td>去重计数</td><td><code>COUNT(DISTINCT user_id)</code></td><td><code>nunique()</code></td></tr>
  </tbody>
</table>

<div class="nb-note nb-note--ok"><b class="nb-tag">经典问题</b>“每个用户消费最高的那一单”：SQL 用 <code>ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY amount DESC) = 1</code>；Pandas 用 <code>o.loc[o.groupby("user_id")["amount"].idxmax()]</code>，或者先 <code>sort_values</code> 再 <code>drop_duplicates("user_id")</code>。</div>

## 读取数据集

创建一个人工数据集，并存储在CSV（逗号分隔值）文件 `../data/house_tiny.csv`中

```python
import os

os.makedirs(os.path.join('..', 'data'), exist_ok=True)
data_file = os.path.join('..', 'data', 'house_tiny.csv')
with open(data_file, 'w') as f:
    f.write('NumRooms,Alley,Price\n')  # 列名
    f.write('NA,Pave,127500\n')  # 每行表示一个数据样本
    f.write('2,NA,106000\n')
    f.write('4,NA,178100\n')
    f.write('NA,NA,140000\n')

```

### **加载原始数据集**

```python
import pandas as pd

data = pd.read_csv(data_file)
print(data)
```

### 分离输入与输出

```python
inputs, outputs = data.iloc[:, 0:2], data.iloc[:, 2] #  分离输入和输出,前两列为input，最后一列为output
inputs = inputs.fillna(inputs.mean()) # 用input的均值填充缺失值
print(inputs)
```
